# 🌐 Sunil Social Media App

A modern and responsive social media frontend application built with **React.js**, **Vite**, and **Tailwind CSS**. The application provides a clean user interface for connecting with people, sharing posts, viewing stories, messaging, and managing user profiles.

## 🚀 Tech Stack

- React.js
- Vite
- Tailwind CSS
- React Router DOM
- Lucide React Icons
- React Hot Toast
- Moment.js

---

## ✨ Features

- 🔐 User Authentication UI
- 📰 Social Media Feed
- 👤 User Profiles
- 📸 Stories Section
- 💬 Real-Time Chat Interface
- 🤝 Connections Page
- 🔍 Discover Users
- 📝 Create Posts
- 📨 Recent Messages
- 🎨 Modern Responsive Design
- ⚡ Fast Performance with Vite

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/sunil-social-media-app.git
cd sunil-social-media-app
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

Application will run on:

```bash
http://localhost:5173
```

---

## 📦 Build for Production

```bash
npm run build
```
